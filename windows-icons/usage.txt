The file that matters is windows-icons/icon.ico: it carries all nine sizes.
The PNGs next to it are for pages, stores and documents.

PyInstaller
    pyinstaller --onefile --windowed --icon windows-icons/icon.ico app.py

Tkinter window
    root.iconbitmap("windows-icons/icon.ico")

Shortcut, Win32 resource (.rc)
    1 ICON "windows-icons/icon.ico"
