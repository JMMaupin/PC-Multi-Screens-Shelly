An older copy can no longer damage the configuration, and a power strip whose name stopped resolving is found again by its address.

Illustrated guide: **[jmmaupin.github.io/PC-Multi-Screens-Shelly](https://jmmaupin.github.io/PC-Multi-Screens-Shelly/)**.

## Install

Download `ShellyPCScreens-{version}.exe` and run it: it offers to update the installed copy, and asks for an administrator once. Running instances in every session close by themselves first.

The executable is not signed yet: on first launch, SmartScreen shows *Windows protected your PC* → *More info* → *Run anyway*.

## Fixes

- **An older copy no longer rewrites the configuration.** Each file now records the version that wrote it (`written_by`). A copy older than the newest of them writes nothing, drives no device, and says so: blue icon, *Version 3.1.1, older than its configuration (3.2.0): changes nothing* in its menu, and a notification at start. Before, an old copy still installed, started by Windows while a newer one was being tried, rewrote `state.json` in its own format: the screen layout and the fixed addresses were lost. Only versions from this one on respect the rule: an older copy than 3.1.1 still installed somewhere can still do the damage, so keep the installed copy up to date.
- **A power strip is asked at its last known address first.** It used to be looked for by its `.local` name, then by a sweep of the network; its address was tried directly only once known to be fixed. A strip whose name stopped resolving, and whose fixed-address mark had been lost, then stayed unfound for hours while its address answered in forty milliseconds. The address is now tried first, kept only if the MAC that answers is the strip's own.
- **The sweep finds strips with the newer firmware.** The Power Strip 4 Gen4 now reports itself as `PowerStripZB`, a name the sweep did not know: it skipped the strip, even when looking for its precise MAC. A known MAC now settles the matter alone, whatever the device reports.

Version numbers now always have three parts: 3.1.1 is a fix of 3.1.0.
