# Screenshots for the site

Each page shows a "Screenshot to come" box until the file below exists.
Drop raw captures, with any name, in `captures/` at the root of the
repository (ignored by git: they show private data); they are then
cropped, masked and saved here under the exact names below.

Capture a single window: **Win+Shift+S** → *Window mode*. App in English,
light theme, for a consistent site.

**Private data is masked** before anything lands here: mDNS names (they
contain the devices' MAC addresses), IP addresses and Wi-Fi network names
are replaced with example values.
